# Saolos

Desarrollador de software y especialista en seguridad de la información. Mi enfoque de trabajo combina el análisis de vulnerabilidades, auditoría de redes, criptografía aplicada y el diseño de arquitecturas web seguras y escalables.

---

### Áreas de Enfoque

- **Seguridad Defensiva & SOC:** Desarrollo de plataformas SIEM, monitoreo de telemetría en tiempo real, detección de intrusiones y sincronización automatizada de reglas de cortafuegos.
- **Auditoría & Trazabilidad Criptográfica:** Implementación de cadenas de custodia con sellado SHA-256, autenticación multifactor (2FA/TOTP), RBAC e inspección forense de metadatos.
- **Sistemas Empresariales & Gestión:** Construcción de aplicaciones web Full Stack orientadas a la administración documental, control logístico, kardex y gestión de flotas.

### Proyectos Destacados

#### Ciberseguridad, SOC & Auditoría
- **[ThreatGuard SOC](https://github.com/saolos12/threatguard-soc):** Plataforma SIEM ligera para ingesta de eventos de seguridad en tiempo real, motor de detección de amenazas y mitigación automática mediante sincronización con el firewall del host.
- **[IT Asset Sentinel](https://github.com/saolos12/it-asset-sentinel):** Sistema de gestión patrimonial y trazabilidad de activos de TI con generación de actas de entrega digitales selladas criptográficamente con SHA-256, RBAC y 2FA/TOTP.
- **[NetScan Sentinel](https://github.com/saolos12/netscan-sentinel):** Escáner de red local de alto rendimiento con detección activa de hosts (ARP/ICMP), resolución NetBIOS/mDNS, auditoría de puertos y banner grabbing.
- **[Metadata Wiper](https://github.com/saolos12/metadata-wiper-cli):** Herramienta CLI y GUI para inspección y sanitización forense de metadatos en documentos PDF, Microsoft Office, OpenDocument e imágenes rasterizadas.
- **[Password Security Lab](https://github.com/saolos12/password-security-lab):** Analizador de entropía de Shannon, detección de patrones de teclado y verificación segura contra bases de datos de brechas utilizando k-anonimato (Zero-Knowledge).

#### Sistemas Web Institucionales & Gestión
- **[Sistema de Gestión Documental](https://github.com/saolos12/sistema-gestion-documental):** Aplicación SPA para radicación, clasificación, asignación de hojas de ruta y trazabilidad de correspondencia institucional interna y externa.
- **[Sistema de Bitácoras YLB](https://github.com/saolos12/sistema-bitacoras-ylb):** Plataforma web para el control de transporte institucional, despacho vehicular en puntos de control y gestión de rutas en Yacimientos de Litio Bolivianos.
- **[Mining Inventory System](https://github.com/saolos12/mining-inventory-system):** Sistema de control de inventario de insumos mineros, registro de movimientos de almacén y cálculo de existencias Kardex con exportación a PDF.

#### Entornos Educativos
- **[Portal de Noticias Security Demo](https://github.com/saolos12/portal-noticias-seguridad-demo):** Entorno web controlado para demostraciones prácticas de telemetría de navegación, gestión de sesiones y pruebas de concepto en ciberseguridad.
